# タッチロック (TouchLock)

Android 用のシンプルなタッチロックアプリ。YouTube などを再生中に画面タッチを無効化して、赤ちゃんが触って再生が止まるのを防ぐ。

## 使い方

1. アプリを開いて「ロック開始」をタップ
   - 初回は「他のアプリの上に表示」の許可が必要
   - ストア外インストールの場合、Android の「制限付き設定」でブロックされることがある。その場合は 設定 → アプリ → タッチロック → ︙ →「制限付き設定を許可する」を先に有効化する
2. 画面に出る 🔓 ボタン（ドラッグで移動可）が待機状態
3. YouTube で動画を再生してから 🔓 ボタンをタップ → ロック（全画面オーバーレイが全タッチを吸収）
4. 解除は **音量ボタン**（上下どちらでも。音量の変化を検知する方式）
   - 保険として、ロック中の右下 🔒 マークの3秒長押し、または通知の「ロック解除」でも解除できる

## 仕様

- 対応: Android 8.0 (API 26) 以降
- 依存ライブラリなし（Android フレームワークのみ、Java）
- 権限: SYSTEM_ALERT_WINDOW（オーバーレイ表示）、FOREGROUND_SERVICE_SPECIAL_USE、POST_NOTIFICATIONS
- ロックはフォアグラウンドサービスのオーバーレイで実現。フローティングボタンで開始し、音量変更のブロードキャストと設定値監視の二重で音量ボタンを検知する

## ビルド

通常は Gradle:

```sh
./gradlew assembleDebug
```

Gradle が使えない環境向けに、SDK ツール（aapt2 / javac / d8 / apksigner）だけで APK を作る代替スクリプトも同梱:

```sh
ANDROID_SDK_ROOT=/path/to/sdk JAVA_HOME=/path/to/jdk ./build-apk.sh
```

デバッグ署名の `TouchLock.apk` がプロジェクト直下にできる。
